# AI Job Market Analysis Dashboard

## 📊 Project Overview
This project analyzes AI job market trends using Looker Studio.

## 📂 Dataset
Kaggle: Data Science Job Salaries Dataset

## 📌 Tools Used
- Looker Studio
- Kaggle Dataset

## 📈 Features
- Salary analysis by job roles
- Experience level distribution
- Remote work analysis
- Location-based insights

## 🔍 Key Insights
- Senior roles have highest salaries  
- Data Scientist and ML Engineer are top roles  
- Remote jobs are increasing in demand  
- US companies offer higher salaries
